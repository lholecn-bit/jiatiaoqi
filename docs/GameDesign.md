# 游戏设计描述文件

## 一、基本信息

- **游戏名称**: 夹挑棋
- **游戏类型**: 双人回合制策略棋类游戏
- **技术方案**: Web 前端（HTML + CSS + JavaScript）+ WebSocket 服务（在线对战）
- **目标平台**: 浏览器

## 二、游戏规则

### 2.1 棋盘

- 棋盘为 5×5 的网格（坐标 (0,0) 到 (4,4)），共 25 个交叉点
- 相邻交叉点之间有横线和纵线（共 5 条横线 + 5 条纵线）
- 每个 1×1 小格内有一条对角线，方向按棋盘格交替排列，形成如下图案：

```
*---*---*---*---*
|\  |  /|\  |  /|
| \ | / | \ | / |
|  \|/  |  \|/  |
*---*---*---*---*
|  /|\  |  /|\  |
| / | \ | / | \ |
|/  |  \|/  |  \|
*---*---*---*---*
|\  |  /|\  |  /|
| \ | / | \ | / |
|  \|/  |  \|/  |
*---*---*---*---*
|  /|\  |  /|\  |
| / | \ | / | \ |
|/  |  \|/  |  \|
*---*---*---*---*
```

- 对角线规则：将每个小格 (col, row) 视为棋盘格，当 (col + row) 为偶数时画 `\`（左上到右下），为奇数时画 `/`（左下到右上）
- 由此产生的完整斜线（含方向和经过的点）：
  - `\` 方向斜线：
    - (0,4)→(1,3)→(2,2)→(3,1)→(4,0)
    - (0,2)→(1,1)→(2,0)
    - (2,4)→(3,3)→(4,2)
  - `/` 方向斜线：
    - (0,0)→(1,1)→(2,2)→(3,3)→(4,4)
    - (0,2)→(1,3)→(2,4)
    - (2,0)→(3,1)→(4,2)
- 棋子落在网格的交叉点上

### 2.2 棋盘初始状态

- 黑棋在底行（y=0）：(0,0) (1,0) (2,0) (3,0) (4,0)
- 白棋在顶行（y=4）：(0,4) (1,4) (2,4) (3,4) (4,4)
- 其余交叉点为空

### 2.3 棋子

- 两种棋子：黑棋、白棋
- 黑棋先手

### 2.4 移动规则

- 双方交替移动棋子，每回合移动一颗己方棋子
- 棋子只能沿**有连线的方向**移动（横向、纵向、或该位置存在的对角线方向）
- 沿线可移动任意距离，但路径上不能有任何其他棋子阻挡
- 目标位置必须为空（不能移动到已有棋子的位置）
- 棋子不能超出棋盘边界

### 2.5 吃子规则

移动完成后，以落点为中心，沿所有经过该点的线进行检测，所有方向同时生效：

- **夹（两颗己方棋子夹住敌方棋子）**：

  - 沿某条线的方向，落点的相邻位置是敌方棋子，再下一个位置是己方棋子
  - 即形成"己-敌-己"的排列
  - 中间的敌方棋子被吃掉，变为己方棋子
- **挑（己方棋子插入两颗敌方棋子之间）**：

  - 沿某条线的方向，落点两侧的相邻位置都是敌方棋子
  - 即形成"敌-己-敌"的排列
  - 两侧的敌方棋子被吃掉，变为己方棋子
- **连锁**：

  - 被转换为己方的棋子，可能会与周围棋子形成新的"夹"或"挑"局面
  - 若产生新的吃子条件，继续触发吃子，直到没有新的吃子发生

### 2.6 获胜条件

- 任意一方的所有棋子被吃光（变为对方颜色），则该方输掉游戏
- 若轮到某一方时，该方所有棋子均无法移动，则该方判负

### 2.7 平局条件

- 暂无平局条件

### 2.8 禁手规则

- 无禁手（双方规则完全相同）

## 三、游戏模式

### 3.1 对战模式

- [X] 双人本地对战（两人轮流在同一设备上操作）
- [X] 人机对战（玩家 vs AI）
- [X] 在线对战（通过网络与其他玩家对战）

### 3.2 人机模式规则

- 玩家固定执黑先手
- AI 固定执白后手
- AI 使用启发式策略（优先吃子/连锁，其次偏向中心与推进）

### 3.3 在线模式规则

- 使用 WebSocket 连接服务端，按房间号匹配对手
- 每个房间最多 2 人
- 先加入房间者执黑，后加入者执白
- 走子、重开、认输会实时同步给对手
- 在线模式下仅当前执子方可操作；非己方回合不可落子

## 四、界面设计

### 4.1 主界面

- 游戏标题（"夹挑棋"）
- 模式切换按钮：本地双人 / 人机对战 / 在线对战
- 在线对战连接面板（仅在线模式显示）：
  - 服务器地址输入框
  - 房间号输入框
  - 连接房间按钮
  - 断开连接按钮
  - 连接状态提示

### 4.2 游戏界面

- 棋盘区域（居中显示）
- 当前回合提示（显示"黑方走棋"或"白方走棋"）
- 选中棋子高亮显示
- 合法目标位置高亮显示
- 最后移动标记（在最近一步棋子上显示特殊标记）
- 重新开始按钮
- 认输按钮

### 4.3 结算界面

- 右上角悬浮结果面板（不遮挡棋盘）
- 显示获胜方/结算原因
- 再来一局按钮

### 4.4 获胜动画

- 胜方棋子金色脉冲光环
- 棋盘粒子效果
- 棋盘顶部胜利横幅（黑方胜利/白方胜利）

### 4.5 视觉风格

- 棋盘底色：淡黄色
- 棋盘线条：黑色细线
- 黑棋颜色：黑色实心圆
- 白棋颜色：白色带灰色边框
- 选中标记：高亮边框
- 合法目标：半透明圆点提示

## 五、交互设计

### 5.1 移动操作

1. 点击己方棋子 → 选中该棋子（高亮显示），同时高亮所有合法目标位置
2. 点击合法目标位置 → 移动棋子到该位置，执行吃子判定，切换回合
3. 点击非法或无关位置 → 取消选中
4. 点击另一颗己方棋子 → 切换选中

### 5.2 吃子与连锁可视化

- 吃子时棋子先置灰闪烁，再转换为目标颜色
- 连锁吃子按步骤逐步播放（第 1 步、第 2 步……）
- 每一步都有阶段提示（即将吃子 / 吃子中 / 已转换）

### 5.3 功能按钮

- 重新开始：重置棋盘到初始状态，黑方先手
- 认输：当前走棋方认负，对方获胜

### 5.4 在线模式交互

- 连接成功后显示“你是黑方/白方”
- 人数不足 2 人时显示“等待另一位玩家加入”
- 对方离线时显示等待重连提示
- 在线模式下“重新开始/认输”会向对手同步
