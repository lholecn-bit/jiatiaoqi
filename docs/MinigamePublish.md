# 微信小游戏上架手册（夹挑棋）

本手册覆盖夹挑棋上架微信小游戏所需的**全部资质与流程**。
本项目走 **个人主体 + 免费游玩 + 激励视频广告** 路线（最快可行路径）。

> 政策以微信公众平台官方说明为准，本手册基于 2025-2026 年政策整理，提交前请在
> [微信开放社区](https://developers.weixin.qq.com/community/) 核对最新要求。

---

## 一、路径选型：为什么走「个人 + 免费 + 广告」

| 维度 | 个人 + 免费 + 广告（本方案） | 企业 + 内购 |
|------|------------------------------|-------------|
| 主体 | 身份证即可 | 需营业执照 |
| 版号（ISBN） | **纯棋类不强制**（非赌性） | **必备**（审批 1-3 个月） |
| ICP 备案 | 不涉及（不做在线对战） | 视情况 |
| 变现 | 激励视频广告 | 内购/会员 |
| 上线周期 | 软著出证后约 1-2 周 | 数月起 |

**关键判断**：夹挑棋是纯策略棋类（类似五子棋/跳棋），**不具备赌性**，不属于敏感的「棋牌（含赌）」类目。
微信官方明确：纯棋类个人主体可上架，按免费游戏流程提交软著 + 自查报告即可，无需版号。

---

## 二、上架清单（按顺序办理）

### ✅ 1. 注册小游戏账号
- 地址：<https://mp.weixin.qq.com>
- 类型选**「小游戏」**（不是小程序），主体选**「个人」**
- 需：本人身份证、一个未注册过该类型的微信号
- 完成后获得 **AppID**（开发用）

### ✅ 2. 申请《计算机软件著作权登记证书》（必备，周期最长）
- 机构：中国版权保护中心 <https://www.ccopyright.com.cn>
- 材料：源代码（前 30 页 + 后 30 页）、软件说明书、申请表
- 周期：普通 30 个工作日，**加急 10-15 个工作日**（推荐加急）
- 费用：加急约几百元
- 可用本项目 [`../patent/`](../patent) 里的设计文档作为「软件说明书」素材

### ✅ 3. 配置游戏信息
在微信公众平台：
- **基本设置**：填写小游戏名称、简介、图标
- **类目设置**：选「**游戏 → 棋牌（棋类）**」或平台提供的对应棋盘游戏类目
- **游戏资质**：上传软著证书

### ✅ 4. 填写《游戏自审自查报告》
- 后台提供模板，勾选无违法违规内容即可
- 个人主体纯棋类一般顺利通过

### ✅ 5. 开通流量主 + 创建广告位
- **流量主开通条件**：累计独立访客（UV）≥ 1000（无门槛门槛较低，发布后积累即可）
- 开通路径：微信公众平台 → 流量主 → 开通
- 创建**激励视频广告位** → 获得 `adUnitId`
- 将 [`../minigame/js/ad.js`](../minigame/js/ad.js) 中的 `TEST_AD_UNIT_ID` 替换为真实 ID
- ⚠️ **审核时广告位可暂不就绪**，但建议先接好代码再提交

### ✅ 6. 上传代码与提审
- 微信开发者工具 → 右上角「上传」→ 填版本号
- 后台「版本管理」→ 提交审核
- 审核周期通常 1-7 个工作日

---

## 三、审核常见拒审原因与规避

| 风险点 | 规避方式 |
|--------|----------|
| 涉嫌赌博/赔率 | 纯棋类无下注、无积分兑换，本游戏天然规避；类目勿错选「棋牌（含赔率）」 |
| 诱导分享/强制广告 | 激励视频必须**用户主动触发**且**可跳过**；本项目仅在「认输」后弹出，不强制 |
| 无效功能/体验差 | 确保三种模式都能正常对弈，AI 不会卡死 |
| 资质不全 | 软著必须上传；类目与游戏内容一致 |
| 涉及未成年人 | 个人免费纯棋类一般不强制防沉迷；如被提示再接入实名认证 |

## 五、若日后要做在线对战（进阶）

本版未做在线对战，因它有额外硬门槛。需要时按此推进：

1. **域名 + ICP 备案**（7-20 工作日）：通过云服务商办理，**个人主体也可备案**
2. **SSL 证书**：为域名申请证书，使 WS 服务升级为 **wss://**
3. **改造 [`../online-server.js`](../online-server.js)**：监听 443，启用 TLS
4. **小程序后台配置**：开发设置 → 服务器域名 → **socket 合法域名** 填 `wss://你的域名`
5. **小程序端**：用 `wx.connectSocket` 替代 `new WebSocket`（参考 [`../TechnicalSpec.md`](TechnicalSpec.md) 协议）
6. 端口**仅支持 443**，不能用 IP，不能用 ws 明文
