# 功能规划（Backlog）

> 记录日期：2026-09-03
> 状态：**仅记录，暂不开发**。以下功能先后顺序不代表优先级。

## 需求清单

| # | 功能 | 说明 |
|---|------|------|
| 1 | 悔棋功能 | 支持撤销一步（或多步）操作 |
| 2 | 在线对战支持第三方观察棋局 | 允许旁观者进入对局观看，不参与落子 |
| 3 | 新手引导教程 | 用户首次进入可先走一遍规则教程；之后可点击教程入口再次学习 |
| 4 | 管理员功能 | 管理员可进入所有在线房间查看实时棋局 |
| 5 | 历史记录 | 记录所有房间的历史对局 |
| 6 | 回放功能 | 支持回放历史对局 |
| 7 | 吃子特效优化 | 优化吃子（夹/挑/连锁转换）的表现效果 |
| 8 | 自定义头像与昵称 | 用户可自定义头像和名字 |
| 9 | 登录功能 | 支持账号登录，同时保留游客模式 |
| 10 | 持久化数据存储 | 引入数据库持久化记录所有比赛数据 |

## 后续处理约定

- 开始开发某条需求前：从本清单移除并新建对应的需求/设计条目（可参考 `docs/ProductRequirements.md` 与 `docs/GameDesign.md` 的格式），必要时同步更新技术文档。
- 需求优先级的调整与取舍由产品侧决定，本文件不预设顺序。
